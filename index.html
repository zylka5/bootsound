1. Connect radio

Connect the radio with a USB cable, turn it on in normal mode. If the port is busy, close the other program and unplug the cable for 2 seconds.

🔊 Volume / Gain

Boost a quiet recording. +6 dB = about 2x louder. If the meter hits 0 dB, the sound will clip - use Normalize instead.

0 dB

📈 Normalization

Sets the loudest peak to the chosen level. Best way to make a quiet file loud without clipping.

✂️ Trim silence

Removes silence so the radio does not wait. Threshold = what counts as silence. Min. silence = how long silence must last to be cut.

-35 dB
250 ms

Tip: first Trim silence, then Normalize. The .bin file respects your selection on the waveform and the size limit from Upload settings.

Upload settings

Address and size must match your firmware. If you don't know, leave defaults.

3. Upload

Uploading will overwrite the old startup sound.

After upload, on the radio: MENU -> POnMsg -> Logo (or Default). If POnMsg is OFF / Message / Full, the radio will not play the sound at startup.

Status

Sound playback is supported only by SONIC firmware after setting option 30 to Logo: MENU -> POnMsg -> Logo
